# Schedule 0.0.8 · 同步前确认冲突

本地构建，尚未发布到 GitHub。配套 Android 1.1.6。

- 手机新增 A、电脑新增 B 时，按稳定编号合并为 A+B。笔记、想法、项目、原图和日程均参与同步。
- 同一记录两端修改，或一端删除、另一端修改时，暂停整次同步。电脑发送系统通知，并在蓝牙同步页展示双方版本。确认前不写入本次合并结果。
- 逐项选择电脑或手机版本后继续同步。确认记录持久保存，退出窗口或重启不会替用户做选择。重连时重新核对双方内容，过期选择不生效。
- 修复带图片与字面列表的想法在重试时被误判为冲突的问题。原图不压缩。

覆盖安装前保留原应用及数据目录。Android 沿用原签名，不卸载、不清空。
0.0.8 的确认流程适用于完整日记同步协议。旧版仅共享日程协议继续兼容；建议两端同时使用本配套版本。

## English

Local build, not yet published to GitHub. Companion: Android 1.1.6.

Independent additions merge by stable ID. Concurrent edits or edit/delete conflicts pause the entire transaction before applying changes. Windows notifies the user and displays both versions for explicit selection. Review decisions survive restart and are checked against current content on reconnect. Stale choices require another review.

Image markup and literal list text now survive desktop conversion without false conflicts on retry. Original images remain uncompressed. Install over the existing app and keep its data directory. The desktop review flow applies to full-journal sync; the legacy shared-event protocol remains compatible.
