# Schedule v0.0.2

项目总览现在可以直接查看图片、打开网址与当天关联资料。

## 中文说明

### 修复与优化

- 修复项目总览把图片显示为“[图片]”的问题，支持正文与图片混排。
- 修复纯图片想法被隐藏、漏计数量的问题，多项目绑定和“未绑定”入口均保留图片想法。悬浮预览以“[图片]”标明这类想法。
- 粘贴图片后即时更新项目总览，保存并重启后仍可查看。
- 项目总览识别 HTTP/HTTPS 网址及 Markdown 网页链接，点击后交给系统默认浏览器打开。
- 支持点击总览正文中的 Windows 路径；含空格的路径请用双引号括起。
- 按日期显示“当天资料”，可直接打开关联文件与文件夹。资料保持按天归属，打开时使用其记录日期，避免误打开当前编辑日期的文件。
- 图片数据缺失、文件路径失效时给出明确提示。网页打开仅允许 HTTP/HTTPS 协议。

### 下载与升级

下载 **`Schedule-0.0.2-windows-x64.zip`**，完整解压后双击 **`Journal.exe`**。需要 Windows 10/11 x64、.NET Framework 4.8 和 [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)。程序无需安装，仍未进行代码签名。

旧用户请先从托盘退出并备份 `%LOCALAPPDATA%\CodexJournal`，再覆盖原程序文件夹。保留原路径和文件名以继续使用快捷方式与通知身份。本版不更改数据结构，不删除已有图片、想法、项目关系或文件关联。

## English notes

### Fixes and improvements

- Project overviews now render images inline instead of replacing them with “[图片]” text.
- Image-only ideas remain visible and count toward idea totals, including multiple-project and unbound views. The floating preview identifies these ideas with an image placeholder.
- Newly pasted images update immediately in the overview and remain visible after save/restart.
- HTTP/HTTPS URLs and Markdown web links open through the default browser.
- Windows paths in overview text are clickable. Enclose paths containing spaces in double quotes.
- Date sections now include their linked files and folders. These resources remain day-level attachments; opening them uses their own record date rather than the currently selected editor date.
- Missing image data and unavailable files show clear messages. External web opening accepts only HTTP/HTTPS schemes.

### Download and upgrade

Download **`Schedule-0.0.2-windows-x64.zip`**, extract the whole archive, and run **`Journal.exe`**. Requires Windows 10/11 x64, .NET Framework 4.8, and the [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/). No installer is needed; the executable is unsigned.

Existing users should exit from the tray, back up `%LOCALAPPDATA%\CodexJournal`, and overwrite the original program folder. Keep the same location and executable name to retain shortcuts and notification identity. This release does not change the data schema or remove existing images, ideas, project bindings, or file links.

Both READMEs and these versioned notes are included in the download. The v0.0.1 release and its notes remain available.
