# Schedule 0.0.7

## 简体中文

### 项目关联更直接

- 顶部项目选择器跟随光标所在的想法，选中或取消项目立即生效，支持多项目绑定，无需另起一行。
- 光标不在想法内时，选择器仍用于设置后续新想法的默认项目。修复点击项目复选框后丢失编辑位置的问题。
- 左侧项目名后用括号显示总想法数，按未完成想法数从多到少排序，同数保持原顺序。绑定和完成状态改变后立即更新。
- 普通笔记也计入未完成想法，但不会因此自动进入待办。空想法不计数，多项目想法在各关联项目内各计一次。

### 在项目总览直接书写

- 打开项目即可在总览输入区写下想法，自动保存到今天，并绑定当前项目。“未绑定”总览也支持直接书写。
- Enter 换行，Shift+Enter 保存当前想法并继续下一条。支持中文输入和直接粘贴图片，已有记录、项目关联及默认绑定设置保持不变。
- 即使右侧仍在查看历史日期，项目输入也归入今天。切换项目后，新输入使用新项目。保存后的内容在总览显示图片、公式和链接。

### 可调节的右侧写作区

- 拖动右侧记录区左边的分隔线，向左拖动即可加宽。双击恢复默认，支持左右方向键、Home / End 调节。
- 宽度自动保存，重启后恢复。窗口较小时限制实际宽度，放大后恢复偏好，保留日历的可用空间。
- 项目总览同样支持调宽；展开当天时仍使用完整区域，单栏布局不显示分隔线。

### 下载与升级

下载 **`Schedule-0.0.7-windows-x64.zip`**。从托盘退出旧版，备份 `%USERPROFILE%\.schedule`，再将压缩包**完整解压**到原程序目录。继续使用原来的 `Journal.exe` 和快捷方式。

数据目录和 Codex / Claude Code 接口保持不变，无需重新导入记录。下载包包含中英文 README、最新演示截图、技能集成、离线公式字体及本版发布说明。截图仅使用演示数据。

## English

### Immediate project bindings

- The top project picker follows the idea at the caret. Add or remove bindings immediately, including multiple projects, without creating a new line.
- Outside an idea, the picker still sets defaults for future ideas. Clicking project checkboxes no longer loses the writing position.
- Project names now show total idea counts in parentheses and sort by unfinished idea count, preserving the original order on ties. Binding and completion changes update the list immediately.
- Ordinary notes count as unfinished ideas without automatically becoming todos. Empty ideas are excluded; an idea linked to multiple projects counts once in each project.

### Write directly in project overviews

- Write in a project's overview to save an idea to today with that project automatically attached. The unbound overview supports the same flow.
- Enter adds a line; Shift+Enter saves the current idea and starts the next. Chinese input and pasted images are supported, while existing entries, bindings and default project settings are preserved.
- New project input goes to today even when the right editor shows an older date. Switching projects changes the binding for new input. Saved overview entries display images, equations and links.

### A resizable right editor

- Drag the divider at the editor's left edge; moving left widens the writing area. Double-click to reset, or use arrow keys and Home / End.
- The preferred width survives restarts. Smaller windows constrain the displayed width while retaining the preference for larger windows and leaving room for the calendar.
- Resizing works alongside project overviews. Expanded days still use the full area; single-column layouts hide the divider.

### Download and upgrade

Download **`Schedule-0.0.7-windows-x64.zip`**. Exit the old version from the tray, back up `%USERPROFILE%\.schedule`, and extract the **entire archive** over the existing app folder. Keep the existing `Journal.exe` and shortcut.

The data location and Codex / Claude Code API are unchanged; no record import is needed. The archive includes both READMEs, updated demo screenshots, assistant integration, offline math fonts and these release notes. Screenshots use synthetic data only.
