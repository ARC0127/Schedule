# Schedule · Windows 0.0.14 + Android 1.1.13

## 中文

- Android 后台通知固定显示「后台服务已开启」，不再把同步进度、连接中断或失败原因反复显示在通知栏。同步页仍可查看实时状态、上次成功时间和错误详情。
- 默认自动同步间隔改为 **1 小时**。升级时，旧的 2 小时设置一次性改为 1 小时，保留配对设备、暂停状态及上次成功时间。已有 4／8 小时设置保留，升级后手动选择 2 小时也会正常保存。
- 保留恢复连接后同步、保存改动后空闲时同步，以及电脑端的冲突确认。Android 仍需保留系统要求的静默前台服务通知，日程提醒通知不受影响。

**更新方式**：已安装 Windows 0.0.13 / Android 1.1.12 的用户可在应用内检查更新。Windows 使用顶部下载图标，Android 使用「同步 → 软件更新」，安装由系统确认。建议两端都更新，周期由电脑协调。更早版本需手动覆盖安装，不要卸载或清空数据。

发布包含 Windows ZIP、同签名 Android APK 和两端合并包。Android 通知行为与覆盖升级在模拟器验证，HyperOS 最终显示方式仍由系统通知设置决定。此前实机蓝牙错误 10022 未在本次修改中修复。

## English

- Android's background notification now has fixed text, “Background service enabled.” Transfer progress, disconnections and failure messages no longer repeatedly update the notification. Live status, the last successful sync and error details remain available on the Sync page.
- Automatic sync now defaults to **one hour**. On upgrade, legacy two-hour settings migrate once to one hour while retaining the paired device, paused state and last successful sync. Existing four/eight-hour settings remain unchanged. Choosing two hours after upgrading is also retained.
- Reconnection sync, idle sync after saved changes and desktop conflict review remain available. Android still requires a quiet foreground-service notification; scheduled reminder notifications are unaffected.

**Updating:** Windows 0.0.13 / Android 1.1.12 users can check for updates in the app. Use the Windows toolbar download icon or Android **Sync → Software updates**, then confirm installation. Update both devices because Windows coordinates the interval. Older versions need an in-place manual upgrade; do not uninstall or clear data.

Includes a Windows ZIP, same-signed Android APK and combined download. Android notification behavior and in-place upgrade retention are tested in an emulator; HyperOS controls the final presentation through system notification settings. The previously reported physical Bluetooth error 10022 is not fixed by this release.
