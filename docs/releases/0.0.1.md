# Schedule v0.0.1

**把想法留在今天。 / A place for today's ideas.**

Schedule 的首个公开版本，由 [ARCLIGHT](https://arc0127.github.io/) 制作，采用 MIT 许可证。

## 中文说明

### 下载与运行

下载附件 **`Schedule-0.0.1-windows-x64.zip`**，完整解压到固定、可写的文件夹，双击 **`Journal.exe`**。应用显示名为 **Schedule**，无需启动 localhost 服务。

- 系统：Windows 10/11 x64。
- 运行依赖：.NET Framework 4.8、[Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)。
- 无需 Python、Node.js 或开发工具。GitHub 的 “Source code” 附件仅提供源码。
- 程序尚未进行代码签名，Windows 可能显示发布者验证提示。

### 本版功能

- 月历与年度热力图，按想法数量归一化显示绿色深浅，重要事项使用偏红色标记。
- Enter 换行、Shift+Enter 添加想法、Ctrl+V 粘贴图片；单按 Ctrl 切换当前想法的完成状态。
- 想法可关联多个项目，支持未绑定入口与跨日期项目总览。
- 本地文件／文件夹拖入与路径关联，直接打开原文件。
- 每天一条日程和 Windows 系统提醒。
- 透明悬浮图标、当天预览、托盘、可选开机启动与可调宽侧栏。
- “想法”统一命名、旧数据兼容及 ARCLIGHT 制作信息。

### 数据与升级

数据位于 `%LOCALAPPDATA%\CodexJournal`。升级前从托盘退出并备份整个数据目录，再覆盖原程序目录中的文件。保留原程序位置及 `Journal.exe` 文件名，继续使用原快捷方式和 Windows 通知身份。

旧版想法字段会自动迁移，保留原记录 ID、项目关系和完成状态。下载包不包含任何个人日志或项目数据。

### 当前边界

界面目前为中文。尚未实现 Markdown 导入导出、SQLite 或正式 Codex skill/CLI 并发编辑接口。Windows 通知设置、免打扰、休眠或关机可能影响提醒投递。

## English notes

The first public release of Schedule, made by [ARCLIGHT](https://arc0127.github.io/) under the MIT License.

### Download and run

Download **`Schedule-0.0.1-windows-x64.zip`**, extract the whole archive into a fixed, writable folder, and double-click **`Journal.exe`**. The displayed app name is **Schedule**. No localhost server is required.

- Windows 10/11 x64, .NET Framework 4.8, and the [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/) are required.
- No Python, Node.js, or development tools are needed. GitHub's “Source code” attachments are source-only downloads.
- The executable is unsigned; Windows may display a publisher verification prompt.

### Included in this release

- Monthly and yearly calendar views with green intensity normalized by idea count, plus reddish importance markers.
- Enter for a line break, Shift+Enter for an idea, Ctrl+V for images, and a standalone Ctrl tap to toggle completion.
- Multiple project bindings per idea, an unbound view, and project overviews across dates.
- Local file/folder drops, path links, and opening files in their original locations.
- One event per day with Windows reminders.
- A transparent floating icon, today's preview, system tray, optional startup at sign-in, and a resizable sidebar.
- Consistent idea terminology, legacy data migration, and ARCLIGHT creator information.

### Data and upgrades

Data lives in `%LOCALAPPDATA%\CodexJournal`. Exit from the tray and back up that entire folder before upgrading, then overwrite the existing program folder. Keep the same executable location and `Journal.exe` name to retain shortcuts and Windows notification identity.

Legacy idea fields migrate while retaining IDs, project bindings, and completion states. The download contains no personal journals or project data.

### Current scope

The app interface is currently Chinese. Markdown import/export, SQLite, and a formal Codex skill/CLI concurrent-editing interface are not implemented yet. Notification settings, Do Not Disturb, sleep, and shutdown may affect reminders.

The archive includes both READMEs and a copy of these release notes. This versioned document remains in the repository independently of future README edits.
