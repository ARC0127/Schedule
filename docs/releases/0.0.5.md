# Schedule 0.0.5

## 简体中文

### 多行想法与离线公式

- 修复粘贴多行文字或 TeX 后，项目总览只显示第一行的问题。普通换行、空行和未缩进的续行都保留在同一个想法中；使用 **Shift+Enter** 添加下一个想法，**Enter** 仅换行。
- 支持 `\(...\)` 行内公式，以及 `\[...\]`、`$$...$$` 独立公式。公式可以跨行，日记编辑区与项目总览都能渲染。
- 点击公式或进入编辑区可编辑原始 TeX，离开编辑区后显示公式。保存、复制、撤销和重启保留原始内容、项目绑定及完成状态。
- KaTeX 与字体随程序附带，公式在本机离线渲染。公式语法有误时保留可编辑的源码，不隐藏正文。
- 悬浮预览保留完整的多行想法文字。悬浮窗仍使用文本预览。

例如，以下内容可以放在同一个想法中：

```text
Diffusion \(x_\tau=\alpha_\tau x+\sigma_\tau\epsilon,
\qquad
\epsilon\sim\mathcal N(0,I).\)
flow matching \(x_\tau=(1-\tau)\epsilon+\tau x.\)
```

### 下载与升级

下载 **`Schedule-0.0.5-windows-x64.zip`**。先从托盘退出旧版并备份 `%USERPROFILE%\.schedule`，再将压缩包**完整解压**到原程序目录，包含 `katex` 文件夹。继续使用原来的 `Journal.exe` 和快捷方式。

沿用 0.0.4 的统一数据目录与保存保护。之前已经保存的完整多行源码会重新显示，无需重新粘贴。压缩包包含中英文 README、首页图、许可证及本版发布说明。

## English

### Multiline ideas and offline equations

- Fix project overviews showing only the first line of pasted multiline text or TeX. Ordinary line breaks, blank lines, and unindented continuation lines stay in the same idea. **Shift+Enter** adds the next idea; **Enter** adds a line.
- Render inline math with `\(...\)` and display math with `\[...\]` or `$$...$$`. Equations can span multiple lines and render in both the journal editor and project overviews.
- Click an equation or focus the editor to edit the original TeX. Leave the editor to preview it. Saving, copying, undo, and restarting preserve source text, project bindings, and completion state.
- KaTeX and its fonts are bundled for offline rendering. Invalid equations remain visible as editable source instead of hiding the text.
- Floating previews retain the complete multiline idea text. The floating window continues to use text previews.

The Diffusion and flow-matching example above can be pasted into a single idea.

### Download and upgrade

Download **`Schedule-0.0.5-windows-x64.zip`**. Exit the old version from the tray and back up `%USERPROFILE%\.schedule`, then extract the **entire archive**, including the `katex` folder, over the original program folder. Keep the existing `Journal.exe` name and shortcut.

The shared data location and save protection from 0.0.4 remain in effect. Previously saved complete multiline source is displayed again without repasting. The archive includes both READMEs, the home screenshot, licenses, and these release notes.
