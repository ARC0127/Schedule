## 中文

### 两端记录，双向合并

- Android 配套应用包含日历、笔记、想法、待办、项目、原图预览和本地提醒。下拉展开日历，左右切换月份或页面，展开后显示事项摘要。
- 笔记、想法、项目名称与绑定、原图和日程双向同步。独立新增自动合并，同一项两端都改过则暂停提交，在电脑逐项确认。等待期间的新修改会使旧确认失效。
- 已配对蓝牙交换连接信息，优先使用加密局域网连接，不可达时尝试手机临时本地热点。无法建立 Wi-Fi 通道时明确回退蓝牙。电脑可能暂时切换无线网络，结束后尝试恢复。

### 图片多，也能接着同步

- 原图独立分批传输，不再占用文字记录的 100 MiB 同步额度。每张原图按 192 KiB 分块写入，保留原始文件字节。
- 已完成并通过校验的原图会保留。连接中断后重新同步，只补传缺少的图片，未完成的一张重新传输。
- Android 同步提交只备份和替换文字、项目与日程元数据，不再把全部图片载入内存，也不受旧的 256 MiB 整包备份额度影响。
- Windows 原图使用独立文件，支持编辑器、大图预览、冲突预览和完整备份导出。
- 同步错误显示失败阶段和对端返回的具体原因。冲突仍须在电脑确认，确认前不会应用记录变更。

### 写作与展示

- Tab / Shift+Tab 缩进与取消缩进，支持多行选区。双击项目内的想法即可原位编辑。
- 项目关联操作在滚动写作时持续可用；从侧栏右键修改项目名称和本地文件夹。
- 单击原图打开简洁预览，点击图片外部关闭。
- 中英文 README 重新整理，增加两端演示图、下载入口与升级说明。Android 源码纳入 `mobile/`，不包含生产签名私钥。

### 升级与验证范围

Windows 从托盘退出后覆盖原程序目录，保留 `%USERPROFILE%\.schedule`。Android 使用同签名 APK 覆盖安装，**不要卸载或清空数据**。两端均更新后启用分批原图协议。

已验证覆盖安装保留笔记、日程与原图。Windows 客户端与 Android 模拟器完成两端各约 **138 MiB** 原图传输，在累计超过 **256 MiB** 原图时提交成功；再次同步只交换约 **80 KiB** 清单。另外验证了断线重试、损坏图片拒绝、元数据恢复、电脑冲突确认与原图备份往返。

这不是实际无线速度测试。红米 K70 / HyperOS 临时热点、蓝牙无线连接与 Windows Wi-Fi 恢复仍需实机验证。临时热点不共享互联网。文字元数据上限 **100 MiB**、单张同步原图 **64 MiB**；原图合计无固定传输额度，仍需可用磁盘空间。Android 手动 ZIP 备份继续使用原有 **256 MiB** 总量限制，新同步恢复不走该路径。旧版兼容通道仍受其整包限制。

## English

### Two devices, two-way changes

- The Android companion includes a calendar, notes, ideas, tasks, projects, original-image previews and local reminders. Pull to expand the calendar, swipe between months or pages, and see item summaries in the expanded month.
- Notes, ideas, project names and bindings, originals and events sync in both directions. Independent additions merge. Concurrent edits pause record changes for desktop review. New edits invalidate stale decisions.
- Paired Bluetooth exchanges connection details. Sync tries encrypted LAN transfer, then a temporary phone hotspot. Unavailable Wi-Fi visibly falls back to Bluetooth. The PC may temporarily change networks and attempts to restore its prior connection afterward.

### Larger photo collections

- Original images transfer separately from journal metadata in 192 KiB chunks, preserving the original bytes. Aggregate images no longer count toward the 100 MiB journal limit.
- Completed, verified originals survive interrupted sessions. Retry transfers missing files only; an incomplete image restarts from its beginning.
- Android commits journal, project and event metadata without loading or archiving every original into memory. The old 256 MiB backup cap no longer limits synchronization.
- Windows stores originals as separate files, including support for the editor, full-size preview, conflict review and complete backup export.
- Sync errors include the failed stage and the peer's reported cause. Conflicts still require desktop approval before record changes are applied.

### Writing and presentation

- Tab / Shift+Tab indent and outdent, including selected lines. Double-click a project idea to edit it in place.
- Project bindings stay accessible while scrolling. Right-click sidebar projects to change their names or local folders.
- Click an original to preview it; click outside the image to close.
- Refreshed Chinese and English READMEs show both apps, downloads and upgrade instructions. Android source is included under `mobile/`, without production signing keys.

### Upgrading and verification

Quit Windows Schedule from its tray before replacing program files. Keep `%USERPROFILE%\.schedule`. Install the same-signed APK over Android Schedule; **do not uninstall or clear its data**. Update both apps for batched originals.

Same-signature upgrade tests preserved notes, events and original bytes. A Windows client and Android emulator transferred approximately **138 MiB** of originals in each direction and committed with more than **256 MiB** combined. A repeated sync exchanged approximately **80 KiB** of metadata only. Interruption/retry, checksum rejection, metadata recovery, desktop conflict review and original-image backup round trips were also verified.

This is not a physical wireless speed benchmark. Redmi K70 / HyperOS hotspot behavior, Bluetooth radio interoperability and Windows Wi-Fi restoration remain unverified on physical devices. The temporary hotspot does not share internet. Metadata remains limited to **100 MiB**, each synced original to **64 MiB**, and aggregate originals to available storage rather than a fixed quota. Android manual ZIP backups retain their existing **256 MiB** total limit; sync recovery uses a separate path. Legacy peers retain their whole-payload limits.
