# Schedule 0.0.6

## 简体中文

### 从想法到完成

- 普通想法默认不进入待办。通过想法的 **… → 设置** 选择普通想法、待办或已完成，可添加重要标记和截止日期。
- 待办页提供未完成 / 已完成，以及全部、普通、重要、日程筛选。未完成事项按逾期、今天、之后和无日期分组，同组重要事项优先。
- 日程可以关联任意日期的想法。完成状态以想法为准，日历、项目和日程同步，关联提醒随完成取消，同一个事项不会重复列出。独立日程仍可单独使用。
- 光标位于想法内时单按 **Ctrl** 完成，再按回到待办。删除、项目绑定和完成操作提供 10 秒撤销，避免覆盖后续冲突修改。

### 更完整的日常工作空间

- 双击日历日期展开当天，占用中侧与右侧区域，使用返回箭头或 Esc 回到原总览。相邻月份的日期可直接点击并自动切月。
- 选中文字后显示简洁格式栏，支持字号、粗体、斜体、下划线和颜色，也可通过文字图标设置接下来的输入。
- 全局搜索覆盖文字、项目、日程与资料。重要事项可跳转到对应日期。项目和搜索保留各自的翻页与滚动位置，侧栏宽度和展开布局也会保存。
- 同一天支持多个日程，各自管理时间与提醒。新增每日快照、手动备份、恢复差异预览、完整备份 ZIP 和 Markdown / 图片导入导出。

### Codex 与 Claude Code

- Windows 包内附带 **Schedule.Cli.exe**、`schedule-local` 技能和安装脚本。通过本机命名管道读写，无需 localhost 服务或额外运行时。
- 读取包含尚在界面中的当前内容，写入使用 revision 校验。支持项目、日期、想法、任务状态与日程；旧版本字段保持兼容。
- 在程序目录运行 `powershell -NoProfile -File .\Install-AssistantSkills.ps1 -AppDirectory . -Target Both`。Codex 使用 `$schedule-local`，Claude Code 使用 `/schedule-local`。详见随包提供的中英文 README 和接口文档。

### 修复与显示

- 启动定位到系统当天，跨午夜、从托盘恢复和唤醒时刷新日期，保留正在编辑或查看历史日期的位置。
- 编辑区和展开日视图实时识别超链接。编辑时 Ctrl+单击打开，离开编辑区后普通单击打开，保留 Markdown 原文与样式。
- 修复公式中的帽子、根号、箭头等 SVG 被图标样式挤压，以及短公式意外出现滚动条的问题。
- 支持每显示器 DPI 缩放，跨屏移动时文字、窗口和悬浮入口按当前显示器重新缩放。
- 更新中英文 README、当前界面首页图与待办总览图。截图仅使用演示数据。

### 下载与升级

下载 **`Schedule-0.0.6-windows-x64.zip`**。先从托盘退出旧版并备份 `%USERPROFILE%\.schedule`，再将压缩包**完整解压**到原程序目录，保留 `katex`、集成技能和配置文件。继续使用原 `Journal.exe` 和快捷方式。

数据目录仍为 `%USERPROFILE%\.schedule`。已有勾选想法归入已完成任务，已有待办和截止日期保持待办属性；普通想法不会自动全部变成待办。完整备份保留图片、项目、格式和内部 ID，关联的外部文件只保留原路径。程序界面目前为中文，Windows 通知仍受系统权限、勿扰模式和睡眠影响。

## English

### From ideas to done

- Ordinary notes stay out of Todo by default. Use an idea's **… → Settings** to choose note, todo or completed, with optional importance and a deadline.
- Todo has pending / completed views and all, ordinary, important and scheduled filters. Pending tasks are grouped by overdue, today, later and undated, with important items first in each group.
- Events can link to ideas from any date. The idea owns completion: calendar, projects and events stay in sync, linked reminders are canceled when completed, and one task appears only once. Standalone events remain available.
- Tap **Ctrl alone** with the caret in an idea to complete it; tap again to return it to Todo. Deleting, changing projects and completing items offer a 10-second undo without overwriting conflicting later edits.

### A fuller daily workspace

- Double-click a calendar date to expand the day across the center and right areas. Return with the back arrow or Esc. Adjacent-month dates are clickable and switch months automatically.
- Selecting text reveals a compact formatting bar for size, bold, italic, underline and color. The type icon also sets formatting for upcoming input.
- Search text, projects, events and resources across all dates. Important items open their date. Project/search pagination and scroll positions, sidebar width and expanded layout are retained.
- Multiple events per day have independent times and reminders. Daily snapshots, manual backups, restore previews, complete backup ZIPs and Markdown/image import and export are included.

### Codex and Claude Code

- The Windows package includes **Schedule.Cli.exe**, the `schedule-local` skill and an installer. A local named pipe connects assistants to the app, with no localhost service or extra runtime.
- Reads include current GUI content. Writes require revision checks. Projects, days, ideas, task states and events are supported, with compatibility for older fields.
- Run `powershell -NoProfile -File .\Install-AssistantSkills.ps1 -AppDirectory . -Target Both` from the app directory. Invoke `$schedule-local` in Codex or `/schedule-local` in Claude Code. Both READMEs and the API reference are bundled.

### Fixes and display

- Startup uses today's system date. Midnight, tray restoration and wake-up refresh it while preserving active editing and historical browsing.
- Links render in the editor and expanded day view. Ctrl+click while editing, or click after leaving the editor, to open them while preserving Markdown source and styles.
- Fix equation accents, roots and arrows distorted by shared SVG icon styles, plus unwanted scrollbars on short equations.
- Per-monitor DPI scaling redraws text, windows and the floating entry when moving between displays.
- Updated Chinese and English READMEs with fresh home and Todo screenshots using synthetic demo data only.

### Download and upgrade

Download **`Schedule-0.0.6-windows-x64.zip`**. Exit the old version from the tray and back up `%USERPROFILE%\.schedule`, then extract the **entire archive** over the existing app folder, including `katex`, integration skills and configuration files. Keep the existing `Journal.exe` and shortcut.

Data remains in `%USERPROFILE%\.schedule`. Previously checked ideas become completed tasks; existing todo flags and deadlines remain tasks. Ordinary notes do not automatically become todos. Complete backups retain images, projects, formatting and internal IDs; linked external files remain references to their original paths. The interface is currently Chinese. Windows notification permissions, Do Not Disturb and sleep still affect reminders.
