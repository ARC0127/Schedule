# Schedule 0.0.15 · 手动分析与追问

发布日期：2026-11-25。配套 **Windows 0.0.15 / Android 1.1.14（版本码 16）**。

- Windows 绑定本地 Codex / Claude Code；手机与电脑均可手动选择资料并提交分析。
- 支持当天、最近 7 天和项目范围，提供来源预览和可选关注问题。
- 请求与报告随已有双向同步传递。普通保存、定时同步和重连不会自动发起分析。
- Codex 按可用目录选择支持 xhigh 的最新旗舰系列，Claude 使用 Opus / xhigh。失败和中断需要手动重试，重复同步不重复调用。
- 独立分析项目保留来源、请求、运行信息和结果，原始记录不改写。图片和关联文件内容不发送。
- 两端同时修改同一请求时仍需电脑确认冲突。助手路径和认证配置只保存在本机。

### 已验证与限制

已验证请求／报告往返、重复同步、取消和失败处理、两端保存与重启。Windows 本机更新后原项目、记录、图片和日程保留，Android 测试使用模拟器。Codex 真实合成资料调用通过；Claude 进程交互测试通过，但本机真实调用在三分钟窗口内未返回，尚未确认成功。此前实机蓝牙错误 10022 未在本版确认解决。OTA 使用互联网，不依赖两端蓝牙连接。

## English

Released 2026-11-25. **Windows 0.0.15 / Android 1.1.14 (version code 16)**.

- Bind local Codex or Claude Code on Windows. Submit selected sources manually from either device.
- Preview a day, the last seven days or a project, with an optional focus question.
- Existing two-way sync carries requests and reports. Saving, scheduled sync and reconnection do not generate requests.
- Codex selects a recent available flagship with xhigh support; Claude uses Opus / xhigh. Failures and interruptions require manual retries; repeated sync does not repeat calls.
- A separate project folder stores snapshots and reports. Original notes remain unchanged; images and linked file contents are excluded.
- Concurrent changes retain desktop conflict review. Executable paths and credentials stay local.

### Downloads and OTA

Use the Windows ZIP, Android APK or combined bundle linked above. In an OTA-capable version, use the Windows toolbar download icon or **Android → Sync → Software updates**. Review the notes and download. Windows verifies, replaces its files and restarts; Android checks package identity and signing certificate, then asks for system installation confirmation. Older versions without OTA need one manual in-place upgrade.

See [Analysis & questions](https://github.com/ARC0127/Schedule/blob/v0.0.15/docs/analysis.md). Preserve `%USERPROFILE%\.schedule` on Windows. Install the same-signed Android APK over the existing app; **do not uninstall or clear data**. Upgrade both sides before syncing analysis requests. Ordinary record sync still defaults to hourly; analysis requires manual submission.

### Verification and limitations

Request/report round trips, duplicate sync, cancellation/failure handling, persistence and restart were tested. Existing Windows records, projects, images and events survived the local update; Android tests used an emulator. A real Codex call with synthetic input passed. Claude process integration tests passed, but a real local call did not return within three minutes and is not yet confirmed successful. The previously reported physical Bluetooth error 10022 remains unverified. OTA uses the internet independently of Bluetooth.
