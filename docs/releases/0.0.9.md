# Schedule 0.0.9 · 原图增量与自动 Wi-Fi 加速

本地构建，配套 Android 1.1.7，尚未发布到 GitHub。

- 修复连接建立四分钟后强制断开的行为。现在只在连续 120 秒没有传输进展时终止连接，持续传输可以超过四分钟。
- 两端交换图片内容标识，只发送对方缺少的原图。首次仍需完整发送新图片，原图不重压缩。现有同步容量限制仍为单次完整日志 100 MiB。
- 蓝牙负责配对和交换连接信息。优先尝试现有局域网，无法直达时尝试手机本地临时热点。无需同一个路由器或手输密码。数据通过 TLS 1.2、蓝牙提供的证书指纹及一次性会话令牌校验。
- 手机需允许“附近 Wi-Fi 设备”（旧安卓可能请求位置权限）。仅有一张无线网卡时，电脑可能暂时离开原 Wi-Fi，完成或失败后恢复。手机临时热点不共享互联网。
- 自动 Wi-Fi 不可用时明确提示并继续蓝牙。电脑可取消“自动使用 Wi-Fi 加速”。两种通道沿用相同的人工冲突确认规则。
- 电脑显示收发数据进度，手机等待期间保持屏幕常亮。主动离开应用仍会停止本次连接。

模拟器与 Windows TLS 客户端验证了多 MiB 原图、重复同步不重传、错误证书/令牌拒绝、数据保留。真实 Redmi K70 / HyperOS 的临时热点建立与电脑无线切换仍需设备验证，不能用模拟器结果代替。

## English

Local build with Android 1.1.7; not published to GitHub. Active transfers no longer stop at a fixed four-minute deadline. A 120-second idle timeout detects stalled connections. Devices exchange image IDs and transfer only missing originals, without recompression. The existing 100 MiB full-journal limit remains.

Paired Bluetooth exchanges endpoint credentials automatically. The client tries an existing LAN first, then a temporary local-only phone hotspot. TLS 1.2 verifies the certificate fingerprint and session token received through Bluetooth. Android requires Nearby Wi-Fi permission (location permission on older releases). A single-adapter PC may temporarily leave its existing Wi-Fi and restore it afterward. The temporary hotspot provides no internet access. An unavailable Wi-Fi path visibly falls back to Bluetooth; Windows can disable automatic acceleration.

Multi-MiB original transfer, repeat-transfer deduplication, invalid certificate/token rejection and data preservation were tested with the actual Windows client and an Android emulator. Physical Redmi K70 hotspot/radio interoperability remains unverified. Install the same-signed APK over the existing app; do not uninstall or clear data.
